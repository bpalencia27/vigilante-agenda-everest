# Lista de Fuentes Documentales Requeridas para Verificación Clínica

> **Objetivo:** Documentos normativos y clínicos oficiales que el médico o auditor debe colocar en `docs/fuentes/` para pasar los elementos de `SIN VERIFICAR` a `VERIFICADO`.
