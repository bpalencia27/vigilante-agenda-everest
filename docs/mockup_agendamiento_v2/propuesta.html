Lo que se corrige

Cada tarjeta viene del código real de openAgendamientoModal, no de una opinión — la línea exacta está en el informe que ya le mandé.

1

Tres pasos siempre

Control + Labs + Medicina General, y aun así 3 pantallas Una tarjeta lista para confirmar, con lo de siempre ya puesto
2

Texto de ayuda repetido

El mismo párrafo largo, cada vez que abre el modal Solo aparece la primera vez; después queda un ícono "¿Qué es esto?"
3

Carga sin avisar cuánto falta

"Consultando horarios..." sin barra ni cancelar Barra de progreso real y botón para cancelar si Everest está lento
4

Fecha manual escondida

Un clic extra para destapar el calendario El calendario ya está a la vista, con el mejor día resaltado
5

Contradicción de seguridad

Labs marcado solo, pero el texto promete "nunca sin decidir" Apagado de fábrica: usted lo prende con un toque, nunca al revés
